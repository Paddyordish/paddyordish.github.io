# Structural Fasteners: Make the Inspection Call

A four-lesson portfolio experience authored in Articulate Rise 360 by Patrick Ordish Elearning.

- Original simple drawings and four labeled hotspots
- Two reused AI-presenter videos, captions and transcripts
- Process walkthrough, sorting, native multiple-choice and matching practice
- Two self-contained HTML5 activities: rotation selection and inspection decisions
- Recap tabs and an inspection-reference PDF

## Delivery

This directory contains the official standalone Web export, hosted on GitHub Pages. It has no LMS tracking. The standard SCORM 1.2 package is stored at `../../downloads/Structural-Fasteners-SCORM12.zip` and uses 100% course completion with Complete/Incomplete reporting.

The Articulate trial watermark is retained. A future paid-account re-export can replace the course files and SCORM ZIP without changing the portfolio link.

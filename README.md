# paddyordish.github.io

## Structural Fasteners: Make the Inspection Call

An independent portfolio course authored in Articulate Rise 360, with two custom HTML5 learning activities.

- [Launch the course](https://paddyordish.github.io/demos/structural-fasteners/)
- [Download the standard SCORM 1.2 package](downloads/Structural-Fasteners-SCORM12.zip)
- [View the inspection reference](downloads/Structural-Fasteners-Inspection-Reference.pdf)

The public web demo does not report to an LMS. The SCORM package uses 100% course completion and Complete/Incomplete reporting. Full build files and source records are retained separately.
